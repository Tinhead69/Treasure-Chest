# Treasure-Chest
A foundry module that creates a treasure chest that can be looted from a scene.  The chest can be trapped and automated by the DM

---------------------------------------------------
Create Treasure Chest

1.  Click the item icon and select create item.
2.  The menu should now show all the items that can be created, select treasure chest
